# Mock concentration-risk review

Use this skill when the user asks whether a mock portfolio allocation is concentrated.

1. Read `references/allocation-thresholds.md`.
2. Compare the stated allocation with the thresholds.
3. Explain the relevant mock educational risk category.

Do not provide individualized financial advice or prescribe portfolio changes.
